## 一、 核心复习与深化模块（20:30–21:10）

### 1. 职业理念（材料题第30题必考，14分）

今日重点攻克**教师观的角色与行为转变**，并闭卷复述三观采分关键词：

#### （1）教师观核心考点（口诀：`见金眼开` / `赞助饭盒`）
- **教师职业角色的转变**（口诀：`见金眼开` / 建进研开）：
  1. **课程的建设者和开发者**（引入课程资源、拓展教学内容、设计特色活动）；
  2. **学生学习的引导者和学生发展的促进者**（启发引导、调动积极性、激发潜能）；
  3. **教育教学的研究者**（反思课堂得失、总结教学规律、探索新型教学模式）；
  4. **社区型的开放教师**（家校社协同育人）。
- **教师教学行为的转变**（口诀：`赞助饭盒` / 赞助反合）：
  1. 对待师生关系：强调**尊重、赞赏**（不伤害自尊心、鼓励肯定、严慈相济）；
  2. 对待教学：强调**帮助、引导**（善于启发、授人以渔）；
  3. 对待自我：强调**反思**（撰写教后日志、复盘得失、主动优化教学）；
  4. 对待与其他教育者：强调**合作**（虚心向同事取经、家校互信）。

#### （2）“以人为本”学生观三维速查（口诀：`学生特意发展`）
- **学生是具有独立意义的人**：学生是学习的主体，不以教师意志为转移；
- **学生是发展的人**：学生具有巨大的发展潜能，处于发展过程中；
- **学生是独特的人**：每个学生具有独特性，教师要因材施教。

### 2. 教师职业道德规范（材料题第31题必考，14分）

- **口诀速记**：`三爱两人一终身`
- **今日重点落实词句**：
  1. **关爱学生**（师德灵魂）：关心爱护全体学生，尊重人格，平等公正，**严慈相济，做学生良师益友；保护学生合法权益，严禁体罚或变相体罚**。
  2. **教书育人**（教师天职）：遵循规律，**实施素质教育，循循善诱、因材施教**；培养良好品行，激发创新精神；**不以分数作为评价学生的唯一标准**。
  3. **爱岗敬业**（本质要求）：勤恳敬业、乐于奉献；**对工作高度负责，认真备课上课、认真辅导学生，不敷衍塞责**。
  4. **为人师表**（内在要求）：严于律己，以身作则；**关心集体，团结协作，尊重同事，尊重家长；廉洁从教**。
  5. **终身学习**（发展动力）：树立终身学习理念，**潜心钻研业务，勇于探索创新，不断提高专业素养和教育教学水平**。

### 2. 材料分析题对标思路（看题理框架）
- **第 30 题（学生观，14分）**：
  - **背景**：语文老师发现学生不敢发言，通过个别鼓励、引导组织语言，探索“辩论教学”“说书教学”“戏剧教学”盘活课堂。
  - **采分点**：
    1. **学生是具有独立意义的人**（学生是学习的主体，调动积极性与创造性）；
    2. **学生是发展的人**（看到学生的发展潜能，允许不足，耐心引导进步）；
    3. **学生是独特的人**（针对内向、胆小、表达不畅的学生因材施教）；
    4. **面向全体学生与全面发展**（不放弃任何学生，促进语言与思维全面发展）。
- **第 31 题（职业道德，14分）**：
  - **背景**：调皮学生赵强公开课打岔问“万万”，老师借题发挥引导全班探究，化解尴尬并表扬感谢赵强；家访不告状反而当父母面夸奖进步；课后针对性辅导制定教学计划。
  - **采分点**：
    1. 践行了**【关爱学生】**（尊重学生人格，平等公正，严慈相济，保护自尊心）；
    2. 践行了**【教书育人】**（因势利导，循循善诱，因材施教，不以成绩定论）；
    3. 践行了**【为人师表】**（以身作则，尊重家长，家校良好沟通）；
    4. 践行了**【爱岗敬业】**（对工作高度负责，课后耐心辅导，制定针对性教学计划）。
